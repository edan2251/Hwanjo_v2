# 원본 레퍼런스 5장

사용자가 현재 대화에서 제공한 파일을 원본 그대로 복사했다. SHA-256와 크기는 reference-manifest.json에 있다.
이미지에 포함된 숫자·기술명·스토리는 자동으로 최신 기능 명세가 되지 않는다.

| 파일 | 역할 |
|---|---|
| Hwanjo_Reference_Character.png | 캐릭터 정체성: 검은 묶음머리, 붉은 스카프, 남색/아이보리 의상, 검 하나 |
| Hwanjo_Reference_Stage1.png | 작은 플레이어와 숲 유적의 비율·깊이. 보스·컷씬 제작 지시 아님 |
| Hwanjo_Reference_4Concept.png | 사방신과 지역 색감 무드. 실제 4속성 대응·월드 지도 확정 아님 |
| Hwanjo_Reference_VFX1.png | 옛 주작 쌍검 3타 시트. 불꽃 호·불티·포즈의 준비/접촉/회수만 참고 |
| Hwanjo_Reference_VFX2.png | 옛 백호 대도 3타 시트. 냉색 궤적·명암·충격 대비만 참고 |

현재 기획: 검 하나·단타 1회·차지 0.5초·사거리 1.75R·검흔 최대1개·4속성 선택.
현재 제작 해석은 ../../docs/element-lab-v01/01_ART_DIRECTION.md를 읽는다.
이 폴더는 참고 원본이며 Unity Assets와 별도다. 원본을 게임용 atlas로 자동 import하지 않는다.
원본의 사용 권리/배포 승인과 새 생성물의 최종 미술 승인은 별도 확인 대상이다.
