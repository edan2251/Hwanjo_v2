# B단계 · 작은 탐험 루프

이 지도·해금 순서는 **이번 프로토타입용 제안**이다. 최종 게임의 월드·스토리 확정이 아니다.
사용자는 탐험·숨겨진 방 확장과 할로우나이트 참고를 요청했다. 아래 규모는 그 요청에 맞춘 제한된 시험 범위다.

## 1. 범위

- 기존 실험실은 유지하고 시작 메뉴에서 `속성 실험실` / `유적 탐험` 선택.
- 실험실은 4속성·더미·반응표·기존 응용 구역을 유지한다. 실험실의 테스트 설정을 탐험으로 자동 승계하지 않는다.
- 탐험은 같은 숲·유적 테마의 **본선 6개 방 + 숨겨진 방 2개**. 방은 논리 구역 수이며, Unity 씬 수를 강제로 8개로 만들라는 뜻이 아니다.
- 새 적 종류는 추가하지 않고 기존 적의 배치와 작은 지형만 변경한다.
- 보스·대규모 이야기·NPC 대화·인벤토리·아이템 제작·새 이동능력·절차 생성은 제외.
- 10~15분 정도로 시험할 수 있는 길이를 목표로 삼되, 실제 사람이 플레이해 시간을 확인하기 전에는 달성했다고 보고하지 않는다.

## 2. 방 구성과 해금안

| ID | 방 | 핵심 행동 | 해금/기억할 것 |
|---|---|---|---|
| E01 | 입구 성소 | 조작·체크포인트·현재 위치 파악 | 불만 보유한 시작 |
| E02 | 물가 갈림길 | 건너기 어려운 수면과 건너편 통로를 먼저 봄. 다른 육로 선택 | 얼음을 얻고 돌아올 장소 |
| E03 | 마른 회랑 | 덩굴 점화, 위쪽 밧줄 베기, 사다리 개방 | 물 획득 |
| E04 | 불붙은 정원 | 물로 위험 열원을 끄거나 안전한 접근 경로 만들기, 짧은 전투 | 불 외에 물의 쓸모 |
| E05 | 샘터 제단 | 얼음 획득, 가까운 작은 수면을 아래 베기로 동결 | E02를 떠올릴 시각 단서 |
| E06 | 깊은 연결 통로 | E02로 돌아와 동결 경로 통과 후 진입 | 바람 획득, E01로 돌아오는 일방향 지름길 개방 |
| S01 | 틈새 기록실 | E03 부근에 보이는 먼 가연성 연결부에 불→바람 전달 | 선택 발견 표식. 필수 권능 없음 |
| S02 | 낮은 숨은 샘 | E06 옆의 작은 공간에서 물 검흔→얼음 받침을 선택 활용 | 작은 발견 표식. 안전한 복귀 가능 |

연결 개념:

```text
E01 ↔ E02 ↔ E03 ↔ E04 ↔ E05
       │        └─ S01 (바람 획득 후 선택)
       └─ E06 ─ S02 (선택)
            └─ E01 (안쪽에서 여는 지름길)
```

E02→E06에 얼음 조건이 있다. E05에서 E02로 돌아오는 길은 처음에는 기존 루트 일부를 재방문하며, 열린 사다리/짧은 연결을 활용해 불필요한 긴 왕복을 줄인다.
불→물→얼음→바람은 **시연용 순서**다. 실험실에는 처음부터 전부 있다. 시작 상태·현재 속성·해금 UI를 구분한다.

## 3. 4방향·1R 기준의 레벨 배치

오브젝트마다 `어디에 서서 / 어떤 방향으로 / 어느 거리에서 / 어떤 속성으로` 적용할지 실제 좌표로 확인한다.
- 위쪽 밧줄은 W+J로 닿는 높이. 정밀한 대각선 조준을 요구하지 않는다.
- 수면은 발밑/앞의 아래 베기로 닿는 노출면을 만든다. 플레이어가 물에 빠져야만 얼릴 수 있는 배치 금지.
- 좁은 반응 판정에 정확히 한 픽셀을 맞춰야 하는 구간 금지. 보이는 수면·밧줄 두께에 맞는 합리적 면적 사용.
- 적은 R와 네 방향으로 대응 가능하게 배치. 대각선에서만 맞힐 수 있는 고정 적을 만들지 않는다.
- 1R 범위 밖의 대상은 길을 돌아 접근하거나, 물체를 옮기거나, 바람 전달을 쓰는 **읽히는 이유**가 있어야 한다.

E02의 물길이 얼음 해금 전 대시/최대 점프로 쉽게 넘어지는지 실측한다. 그렇다고 R·이동 스펙을 방마다 몰래 변경하지 않는다.
충돌 면을 가진 동결 수면은 해당 방을 통과하기 충분한 시간을 제공한다. 맵 수면 동결은 이 구간에서 **방 재설정 전까지 유지**하는 시험안을 우선 사용한다. 이는 기존 실험실의 자동 해동 시간과 분리한 구역 데이터이며 최종 규칙이 아니다.
임시 검흔 2초와 맵 동결 유지시간을 하나의 전역 변수로 묶지 않는다.
지형 제한만으로 해금 관문을 유지할 수 없는 경우 원인을 보고하고 좁은 범위 안에서 방 배치를 재설계한다. 게임 전체에 투명벽을 덧대지 않는다.

## 4. 숨겨진 방과 재타격 검증

숨겨진 입구에는 빛 틈·이어진 뿌리·바람에 움직이는 천 등 관찰 단서를 둔다. 모든 벽을 공격해야만 발견하는 무작위 비밀 방식 금지.
발견 전 지도에 방 실루엣을 노출하거나 카메라/패럴랙스가 벽 밖을 보여줘 정답을 누설하지 않는다.
S01·S02는 선택 경로다. 검흔을 사용하지 않았다는 이유로 본선 전체를 막지 않는다.
발견 보상은 화면 기록/표식 2개로 제한한다. 새 화폐·상점 시스템을 만들지 않는다.
검흔을 필수로 만든 방을 통과했다고 ‘검흔의 필요성이 증명됐다’고 보고하지 않는다. 사용 횟수·실패 이유·입력 부담을 사람에게 질문한다.

## 5. 간단 지도와 복구

- 지도: 방문한 논리 방, 현재 방, 확인한 출구, 이미 발견한 비밀방만 표시. 키 M 제안. 잠긴 속성의 아이콘은 알려진 것만.
- 작은 시작 메뉴·지도·일시정지는 한국어. 실험실 UI와 함께 키충돌 검사.
- E01과 E05에 체크포인트 2개. 접근+상호작용으로 활성화, 활성 상태 명확히 표시.
- 세션 내 유지: 획득 속성, 열린 지름길, 발견한 방/보상, 마지막 체크포인트.
- 사망/재시도: 체크포인트로 안전 복귀. HP 회복, 임시 검흔·속도/공격 modifier 정리. 획득 권능·영구 개방 지름길 유지.
- 방 이동 시 일시 상태는 구역 정책으로 초기화하고 막힌 복귀 동선이 없는지 확인. 활성 불/얼음/움직인 상자를 저장하지 않는다고 영구 지름길까지 되감지 않는다.
- 필수 물체를 없애면 `현재 방 다시 시작`으로 복구 가능. 해금은 보존. 돌아갈 수 없는 위치·천장 끼임·물속 부활 금지.
- 탐험의 R키는 곧바로 전체 진행을 지우지 않는다. 방 재시작 확인 메뉴를 열거나 일시정지 메뉴로 제공한다.
- `탐험 처음부터`는 별도 확인. 실험실 R 전체 초기화는 그대로.
- 프로그램을 껐다 켜도 이어지는 디스크 저장은 이번 필수 범위가 아니다. 세션 내 유지와 영구 세이브를 혼동하지 않고 종료 안내에 명시한다.

## 6. B단계 결과물

실제 연결된 탐험 구역, 한국어 지도/체크포인트/해금 UI, 경로 표, 원래 실험실로 돌아갈 메뉴.
`docs/V02_LEVEL_DESIGN.md`에는 실제 방 ID·출구·필요 속성·획득물·복구 경로·막힘 방지·이동/사거리 실측을 기록한다.
좌우로 방만 나열하거나 출구 텔레포트만 있다고 연결 탐험을 완료 처리하지 않는다. 위아래 이동 구간과 재방문 경로를 포함한다.
