# Element Lab v0.2 · 검증 체크리스트

이 문서는 아직 실행하지 않은 테스트 요구다. 과거 결과를 새 버전 통과로 재사용하지 않는다.
테스트 숫자를 정답으로 맞추지 않는다. 기존 v0.1 보고의 EditMode33/PlayMode23/Windows11은 참고이고 실제 현재 테스트·추가 변경을 실행한다.

## A. 조작·반응

- [ ] 같은 기준점/방향에서 기본·차지의 최대 도달거리가 1R이다. 1.75R 옛 값이 현행 튜닝/UI에 남지 않음.
- [ ] 실제 베기 방향 외의 뒤·반대편 대상에 원형 판정으로 피해를 주지 않음. 좌우만 시각 반전해 위쪽 판정이 남는 버그 없음.
- [ ] J 짧게/0.5초 이상/길게 유지 후 해제는 각각 정확히 한 공격. 기존 취소 규칙·지상 차지·공중 단타 보존.
- [ ] W+J 위, S+J 아래, 좌우 방향, 대각 입력의 수직 우선, W+S 중립 처리 확인.
- [ ] 공격 중 방향/속성 키 변경이 이미 발동한 판정을 바꾸지 않음.
- [ ] 좌우·상하 검흔에 제자리 재타격 가능(아래는 노출 유효 공간). 검흔 생성 때 동일 ActionId로 즉시 소비되지 않음.
- [ ] 검흔이 플레이어를 따라오지 않고 벽 내부·벽 너머에 생성되지 않음. 공간 부족 이유 표시.
- [ ] 지상 물가 아래 베기→수면 동결, 얼음 위 보행, 열로 표면 해동. 불투과 플랫폼 밑의 물에는 전달되지 않음.
- [ ] 수면 동결이 수면 그림/충돌과 맞고 멀리 있는 전체 강을 얼리지 않음.
- [ ] 불/물 바람 전달의 방향, 거리, 첫 적중/벽 종료, 동일 슬롯과 중복 금지.
- [ ] 물 검흔→얼음 구조→물 복귀 시 최초 만료·슬롯·현재 속성/특성/collider가 함께 갱신됨.
- [ ] 얼음 차지의 냉기 흔적과 실제 얼음 구조를 구분. 지지면 없는 무한 발판을 만들 수 없음.
- [ ] 한 대상에 Wet→Dry→Burning 이중 전이 없음. 물체 collider 여럿/지속 접촉/전달체 계보 검사.
- [ ] 적의 화상/물 둔화/바람/직접 동결과 해제·공격 취소가 v0.1 의도대로 유지됨.
- [ ] 미지원·이미 적용·조건 불충족·빗나감·지형 차단이 구별됨.

## B. 한글 UI

- [ ] 메뉴/드롭다운/툴팁/더미특성/프리셋/상태/반응이력/도감/지도/초기화확인창 한국어.
- [ ] 도감 지원표와 실제 반응 데이터 일치. 표시된 효과가 미구현인데 가능이라고 쓰지 않음.
- [ ] 한글 글자 누락/네모/겹침/끝 잘림 없음. UI가 쓰는 모든 문자열을 확인.
- [ ] UI 편집/클릭/스크롤 중 숫자키·J·R·W/S가 게임으로 누출되지 않음.
- [ ] 더미 Reset은 마지막 Apply, 프리셋 기본복원은 별도라는 의미 유지.

## C. 탐험

- [ ] 실험실과 탐험을 각각 새로 시작. 초기 4속성/불1개가 모드별로 정확함.
- [ ] E01~E06 및 S01/S02 실제 존재·출구·방 경계·스폰 위치 검증.
- [ ] E02 물길을 해금 전 일반 이동으로 우회/스킵하는지 실측. 방향/사거리/속도 같은 핵심값을 방마다 조작하지 않음.
- [ ] E03 물→E05 얼음→E02 재방문→E06→성소 지름길 전체 루프 실제 입력으로 진행.
- [ ] 실제 위 베기 밧줄·아래 베기 수면·바람 전달 비밀방 사용. 내부 함수/텔레포트로만 전체 길 통과했다고 보고하지 않음.
- [ ] 동결 수면 정책과 검흔2초 수명이 독립. 본선 필수 경로가 임시 검흔 수명 때문에 진행불능 되지 않음.
- [ ] 죽음/방 재시작/모드 복귀/탐험처음부터의 해금·지도·지름길 유지 범위 각각 확인.
- [ ] 필수 오브젝트 소실·빙결 만료·상자 끼임에서 재시도/대체 출구가 작동.
- [ ] 숨겨진 방은 필수 권능이 없고 관찰 단서 존재. 미발견 지도/카메라가 내부를 누설하지 않음.
- [ ] 미니맵 방문 표시·현재위치·체크포인트, 세션 종료 후 저장되지 않는 범위 안내.

## D. 아트·카메라 자체 검토 — C단계 생략 금지

- [ ] 일반 게임에서 네모 임시 칼이 사라지고 손과 실제 검이 붙음. F1 디버그는 별도.
- [ ] 좌우·위·아래 단타 및 차지의 준비/접촉/회수 포즈와 판정 타이밍 일치.
- [ ] 지상 아래 베기와 공중 아래 베기에서 몸이 통째로 회전하거나 반동 이동하지 않음.
- [ ] 좌우 반전 때 손·검·궤적·기본공격/검흔 판정 일치. clip 개수만으로 판정하지 않음.
- [ ] 기존 묶음머리·붉은 스카프·남색/밝은 옷 유지. 다른 속성에서 별도 무기·폼으로 변하지 않음.
- [ ] 원경/중경/근경 장식이 서로 다르게 움직이며 지형/상호작용 대상은 정확한 월드 위치 유지.
- [ ] 패럴랙스 기준 위치 누적 드리프트·반복이음새·방 경계 빈 배경 없음.
- [ ] 카메라 댐핑 ON/OFF, 점프·낙하·방 이동·부활 시 화면/도트흔들림/착지 시야 확인.
- [ ] 플랫폼 윗면·끝·모서리와 collider 일치. 배경 장식이 발판/가연성 기믹으로 오해되지 않음.
- [ ] 물·동결체·냉기흔적의 그림/충돌 여부 구분. 가독성을 가리는 폭발·전경·어둠 없음.
- [ ] 정지 캡처뿐 아니라 시간순 프레임/짧은 재생 자료를 실제 열어보고 스크롤·동작 확인.

## E. 실행·근거

- [ ] Unity 컴파일·EditMode·PlayMode 최신 결과 XML의 total/pass/fail/skip와 exit code 확인.
- [ ] Windows 빌드 폴더 전체 생성, v0.1 EXE/원본 이미지 해시 보존, 관련 변경범위 확인.
- [ ] 실제 게임 키와 UI 클릭을 통한 조작 확인. 자동 내부함수 호출과 사용자 입력 검증 구분.
- [ ] 최소1366×768·1920×1080에서 HUD/한글/카메라경계 확인. 현재 지원하기 어려운 모드는 미검증 명시.
- [ ] 타깃30/60/120 설정에서 논리 동작 비교. 실제 달성 FPS와 타깃 FPS를 혼동하지 않음.
- [ ] 렌더 캡처와 별개로 짧은 무캡처 성능 샘플을 기록. 짧은 표본으로 지속60/120 보장하지 않음.
- [ ] 종료와 남은 프로세스 확인. 기존 ComputeBuffer 경고·새 오류를 분리하고 원인/영향 미확정은 그대로 기록.
- [ ] A/B/C 각 결과·적용 수치·현재반응표·알려진 문제·인계 위치 문서화.

## 범위 변경 때문에 정당하게 바뀌는 기존 테스트

1. 차지 1.75R의 과거 기대값 → 새 사용자 결정1R. 옛 사거리 테스트를 지우지 말고 새 기대/경계 검사로 갱신.
2. 네 방향 접촉, 가까운 검흔, 한국어 표시, 탐험 모드 추가, 냉기흔적/실체얼음 분리와 같이 이번 명세의 변경은 테스트도 명시 갱신.
3. 무관한 적 피해·반응 우선순위·원본보존 테스트를 실패했다는 이유로 완화하지 않음.

## 사람의 평가와 분리

다음은 자동 테스트 PASS와 별도로 남긴다.
- 4방향이면 원하는 곳을 건드리는가? 정말 대각/360도 조준이 필요한 장소가 반복되는가?
- 1R 차지 후 가까운 검흔은 편한가? 차지는 어떤 선택을 더해주는가?
- 검흔 재타격이 없는 재료를 준비하는 재미인가, 원거리 발사를 위해 입력만 늘어나는가?
- 새 속성 획득 후 E02를 떠올리는가? 숨은 방 단서가 억지스럽지 않은가?
- 검/배경/플랫폼이 보기 좋아지면서 상태·착지점도 더 잘 보이는가?

기능/아트 자체 검토 완료는 사람 미술 승인과 다르다. 누락/대체 표현을 PASS 뒤에 숨기지 않는다.
