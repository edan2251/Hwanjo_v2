# A단계 · 조작과 반응을 사용할 수 있게 만들기

## 1. 변경의 지위

- 사용자 확정: 차지 단독 도달거리 **1R**. 기본 베기의 실제 R 자체를 몰래 키워 변화 전 사거리를 유지하지 않는다.
- 사용자 요청: 검흔 근접 생성, 발밑 물 상호작용, 반응 안내 한글화, 검흔 필요성 재검토.
- 권장 실행안: **4방향 선택 공격(좌/우/위/아래)**. 한 번의 공격은 선택한 방향의 궤적만 판정한다.
- 유지: 검 하나, 단타 1회, 0.5초 차지, 불/물/바람/얼음, 1~4 즉시 선택, 플레이어 검흔 슬롯 1개, 한 ActionId·대상당 한 의미상 상태 전이.
- 유지할 임시값: 검흔 2초, v0.1 피해·적 상태이상·이동/대시 성능. 새 QA에 꼭 필요한 값만 바꾸고 전후·이유 기록.

기존 1.75R 명세는 v0.1 기록이다. 코드·현재 튜닝·테스트·HUD·현행 SCOPE에는 1R를 반영하고, 과거 패키지는 이력으로 그대로 둔다.

## 2. 실제 구현 조사

기존 Player/Attack/Trace/Reaction/Overlay/Art/Level/Tests와 현재 v0.1 씬을 읽는다. 이름이나 스크립트 경로를 이 문서의 표현과 같다고 가정하지 않는다.
조사 결과에는 실제 R, 기준점, 공격 판정 형상, 검흔 좌표·수명, 입력 확정 시점, collider 중복 방지, 수면 수신 영역, UI 구현 방식을 남긴다.
기존 배경과 주인공을 게임 캡처로 확인한 후 수정한다. 원본 레퍼런스만 보고 현재 모습까지 봤다고 하지 않는다.

## 3. 4방향 입력 — 이번 시험안

| 입력 | 단타 | 차지 |
|---|---|---|
| J | 현재 좌우 바라보기 방향으로 1회 | 같은 방향으로 베어 검흔 생성 |
| W 또는 위 방향키 + J | 위 베기 1회 | 위 차지 베기 |
| S 또는 아래 방향키 + J | 아래 베기 1회 | 아래 차지 베기 |

좌우 이동은 기존 A/D. 기존 방향키 이동을 지원한다면 유지한다. 방향+공격은 새 스킬 버튼이 아니다.
상하 입력이 하나만 있으면 수직을 우선한다. W+D로 움직여도 공격은 위. W+S 동시 입력은 수직 중립으로 보고 마지막 좌우 방향을 쓴다. 추가 8방향·마우스 조준은 금지.
기존 release 판별을 우선 유지: J를 놓을 때 0.5초 미만이면 단타, 이상이면 차지 1회. 공격 방향과 속성은 **공격 발동 순간** 확정하고 유효 판정이 끝날 때까지 변경하지 않는다. 차지 중 미리보기는 입력 방향을 표시할 수 있다.
UI 포커스·지도·일시정지·방 전환·피격·사망 시 대기 차지를 정리한다. UI를 닫고 J를 놓았다고 오래된 공격이 튀어나오지 않는다.

### 지상과 공중

- 지상 아래 베기 허용: 물가에서 점프를 강요하지 않고 노출된 수면/발앞 대상을 친다.
- 공중 단타는 상/하/좌/우를 모두 허용하되 중력·기존 이동 유지. 하단 적중으로 튀어오르기, 급강하, 비행, 점프/대시 횟수 회복은 추가하지 않는다.
- v0.1의 지상 차지 정책을 유지. 공중 차지는 이번에도 기본 OFF. 공중에서 길게 눌러도 착지 후 묵은 차지가 발사되지 않게 한다.
- 위·아래 베기를 위해 전체 캐릭터를 90도 돌리거나 Rigidbody/몸체 collider를 회전시키지 않는다.

## 4. 1R와 실제 판정

기존과 같은 공통 측정 기준점 O를 사용해 선택 방향으로 기본 베기·차지 단독의 전체 최대 도달거리를 비교한다. 기본 R 자체는 유지한다.
위·아래용 기준점을 먼 곳으로 옮겨 숨은 사거리 보너스를 주지 않는다. 실제 기준점·R·몸 높이의 관계는 문서/디버그에서 보여준다.
측면 폭은 기존 베기와 비슷한 명확한 호/영역으로 두며, 보이지 않는 원형 Overlap으로 주변 전체를 처리하지 않는다.
표현상 바깥 불티는 허용하지만 공격처럼 읽히는 큰 궤적은 실제 유효 판정과 맞춘다. 차지를 새 원거리 투사체로 만들지 않는다.

### 접촉과 가림

검·속성·검흔 재타격이 동일한 방향 결정과 접촉 정보를 사용한다. 물체의 중심점만으로 hit 여부를 판단하지 않는다.
닿는 표면은 상호작용하고, 그 표면 뒤의 불투과 지형은 막는다. 얼려 만든 고체 표면의 **표면 자체**는 다시 불로 맞혀 해동 가능해야 한다.
수면 수신 판정은 보이는 수면에 가깝게 둔다. 발밑이라도 실제 1R 밖이거나 중간에 불투과 바닥이 있으면 안 맞는다. 플레이어는 물가/노출면에서 조작할 수 있어야 한다.
빙결은 지정된 물 구간 단위로 한다. 연결돼 보인다는 이유로 화면 밖 강 전체에 적용하지 않는다.
공격이 빗나간 것과 물에 닿았는데 조건이 안 맞는 것을 로그에서 구분한다.

## 5. 검흔 위치·수명

검흔을 차지 사거리 끝에 보내지 말고 **동일 방향의 기본 베기가 닿는 앞 공간**에 생성한다.
임시 위치 후보: O에서 공격 방향으로 약 0.6R. 실제 hitbox·몸 크기에 맞춰 조정하고, 검흔 전체 반응 영역이 의도한 베기 안에 있도록 검사한다.
좌/우 및 위/아래에서 ‘차지→다른 속성 선택→이동 없이 같은 방향 단타’로 재타격 가능해야 한다. 지상 아래쪽은 지면 제약 때문에 노출 표면에서 확인한다.
생성 뒤는 세계 좌표에 고정. 플레이어를 따라다니거나 기본공격에 맞추어 자동 이동시키지 않는다.
막힌 위치는 방향선상의 유효 공간으로 짧게 제한한다. 유효 공간 자체가 없으면 생성 불가 이유를 표시하며 벽 밖/안으로 순간이동시키지 않는다. 생성 실패 시 기존 슬롯을 먼저 지우지 않는다.
자기를 만든 차지 ActionId로 즉시 재타격되지 않게 한다. 새 유효 검흔 생성 때만 이전 슬롯 산출물을 종료한다.
수명은 우선 기존 2초. 실험실에 2초/4초 비교 설정을 노출해도 되지만 기본값은 2초로 두고 변화 이유를 측정한다. 해금 구간의 필수 진행을 2초 검흔 묘기에 의존시키지 않는다.

## 6. 검흔의 역할

검흔은 **직접 적용을 대체하도록 강요하는 절차가 아니라, 부족한 반응 재료를 준비하는 도구**로 시험한다.
환경에 물이 있으면 직접 얼리고, 가연성 밧줄이 닿으면 직접 태운다. 검흔이 반드시 있어야 동일한 기본 반응이 발생하도록 잠그지 않는다.
실험실의 작은 비교 구역에서 ‘같은 목표+미리 놓인 전달 가능한 불씨/물’과 ‘검흔으로 재료 준비’를 비교할 수 있게 한다. 새 원거리 무기·360도 조준 기능은 이 비교 때문에 만들지 않는다.
이 비교는 재료 준비의 가치를 보는 시험이며, 그것만으로 재타격 버튼의 우월함이 증명됐다고 결론 내리지 않는다. 아직 재타격 필요성은 사람 평가 대상이다.

## 7. v0.2 검흔 지원표 — v0.1 동작과 대조해 적용

원래 패키지에 있던 EL 규칙을 재사용한다. 이번 표는 추가 조작 설명과 일부 정리이며 12개의 새 합성기를 만들라는 뜻이 아니다.

| 현재 검흔/산출물 | 불 Heat | 물 Moisture | 바람 WindImpulse | 얼음 Cold |
|---|---|---|---|---|
| 불 검흔 | 유지, 갱신 없음 | 소화·소멸 | 화염 전달 | 소화·소멸: v0.1 지원 동작 보존 |
| 물 검흔 | 이번 버전 미지원: 증기 기능 추가 금지 | 유지, 갱신 없음 | 수분 전달 | 얼음 구조물로 변환 |
| 바람 검흔 | 2차 반응 미지원 | 미지원 | 유지, 갱신 없음 | 미지원 |
| 냉기 검흔(얼음 차지로 직접 생성) | 종료/소멸하는 약화 처리안 | 미지원 | 기존 이동형 프로필이 실제 있으면 냉기 전달 보존, 없으면 미지원 | 유지, 갱신 없음 |
| 물 검흔에서 변환된 얼음 구조 | 해동→물 검흔 | 유지 | 이동 허용형만 밀기. 기존 고정형은 이동 불가 표시 | 유지, 갱신 없음 |

**명시적 수정안:** 얼음 차지의 ‘냉기 흔적’과 물을 얼려 만든 ‘실체 얼음’을 구분한다. 얼음 차지만으로 동일 발판을 무료 생성해 물→얼음 준비를 무의미하게 만들지 않는다.
로컬 v0.1이 서로 다른 동작을 이미 가진 경우 삭제부터 하지 말고 차이를 `docs/V02_CHANGELOG.md`에 적어 이 시험안으로 전환한다. 냉기 흔적이 열로 물까지 만드는 v0.1 동작은 이번 시험에서 종료/소멸로 바꾸는 제안임을 명시한다. 팀 최종 규칙이 아니다.
같은 속성의 유지는 복제·강화·새 수명으로 해석하지 않는다. 바람 검흔은 아직 기능 검토 중으로 표시하고 필수 퍼즐에 쓰지 않는다.

### 전달 방향과 양

불/물 검흔을 바람으로 맞히면 **재타격 방향**으로 전달체 1개. 원래 검흔은 소비하고 같은 슬롯을 이어 쓴다.
기존 v0.1의 실제 전달 거리를 유지한다(이전 명세 시작안은 생성점부터 3R). 1R 변경은 기본/차지 단독 범위에 대한 것이며 바람 전달을 1R로 축소하거나 무한 사거리로 늘리는 뜻이 아니다.
벽 또는 첫 유효 수신 대상에서 종료. 다중 collider와 같은 계보의 입력이 같은 대상을 건조→점화로 연속 처리하지 않는다.
수직 바람 재타격도 같은 전달 규칙을 쓰되, 플레이어를 띄우거나 허공 상승기류를 만들지 않는다.

### 변환된 발판

물 검흔→얼음은 같은 슬롯·최초 만료시각을 유지한다. 지지 지형에 닿거나 기존 허용 기준을 만족할 때만 발판 collider 생성.
검흔 또는 임시 발판을 다시 지지대로 삼는 무한 계단은 금지. 실제 허용 범위/모양/만료 피드백 표시.
맵 수면 동결은 검흔 슬롯과 별개인 환경 상태다. 환경 수면을 얼릴 때 검흔이 지워지거나 검흔이 만료됐다고 맵 얼음이 사라지지 않는다.

## 8. 환경·적 반응 보존

Trait/State/Effect/Consequence 분리, 한 입력 한 의미상 전이 유지.
특성 이름별 C# 분기를 객체 이름별 예외로 되돌리지 않는다. Frozen은 모든 물체의 물리 고정과 같지 않다.
기존 일반 적의 직접 동결(IntrinsicMoisture), 화상 DoT, 물의 이동·공격 진행 둔화, 작은 바람 밀림/상승은 유지하고 재타격·해제 안전만 회귀 검증한다.
DoT가 Heat를 재입력하거나 매 틱 전체 화면을 멈추지 않는다. 새 적·보스·패링·장비 시스템은 추가하지 않는다.

## 9. 한국어 UI·관찰 도구

런타임 화면의 메뉴·설명·토글·드롭다운·상태·오류·키 안내·지도·반응 이력을 한국어로 제공한다. 영어 ID는 개발 상세 보기에서 병기 가능.

| ID 의미 | 한글 표시 예 |
|---|---|
| Flammable | 가연성 · 불이 붙을 수 있음 |
| Wettable / Wet | 젖음 가능 / 젖음 |
| Freezable / Frozen | 동결 가능 / 동결 |
| Pushable / WindReactive | 이동 가능 / 바람 반응 |
| Hit miss | 닿은 대상 없음 |
| WrongState | 조건 불충족: 동결에 필요한 수분이 없음 |
| Unsupported | 이번 프로토타입에서 미지원 |
| Blocked by terrain | 지형에 가려져 전달되지 않음 |
| Already active | 이미 적용 중: 중첩·수명 갱신 없음 |

런타임 반응 도움말은 **실제로 사용하는 반응 데이터**에서 가져오거나 코드-표 자동 일치 검사를 둔다. 표만 갱신하고 로직은 미구현 상태로 남기지 않는다.
더미의 Apply·Reset·Preset·고정/이동·상태 충돌 메시지도 번역. UI 입력이 게임 공격/원소 선택으로 새지 않도록 기존 포커스 방지 유지.
Font 리소스는 프로젝트에서 사용 가능한 한글 지원 자산 우선. 새 리소스가 필요하면 출처·라이선스·제한을 확인하고 기록한다. OS 폰트를 임의로 프로젝트에 복사해 배포하지 않는다.
문자 누락·네모 글자·줄넘침·DropDown 잘림은 실제 Windows UI에서 확인. 한글 ID로 C# 이름을 전부 바꿀 필요는 없다.
