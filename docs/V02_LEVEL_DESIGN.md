이동 속도4.2, 점프8.5/중력23, 대시11·0.16초·0.55초 재사용 그대로다. 점프의 수학적 최대 상승 약1.57, 비행 약0.74초는 배치 참고값이다. 실제 13-unit 수면을 점프와 재대시로 넘지 못하고 성소로 복귀함을 `07-B-play`에서 검사했다. 물리 값이나 R를 방별로 변경하지 않는다.

수면은 `TimedStatuses=false`인 환경이다. 방 이동/재설정 시 복구하며, 검흔2초가 지나도 얼린 수면은 유지한다. 획득 권능·개방 계단·정원 문·성소 지름길·발견 기록은 방 재시작/사망으로 지우지 않는다. R은 확인창, 전체 초기화는 별도 확인이다.

지도는 방문한 방만 그린다. 숨은 방 내부는 별도 방 루트에서 만들어져 발견 전에 카메라/패럴랙스로 새지 않는다. 출구는 가까이서 E로 이동하되, 각 방 내부의 높이·반응 관문은 직접 통과해야 한다. 10~15분 인간 플레이 길이는 아직 측정하지 않았다. 전체 실제 입력 동선과 화면 검수는 `V02_VALIDATION.md` 결과를 따른다.

## 통합 재생 중 수정한 복귀 경로

E01/E05의 0.85 높이 계단을 바닥까지 채우고, 상단 플랫폼 오른쪽에도 1.7→0.85 높이의 계단을 연결했다. 실제 재생에서 E05 수면을 시험한 뒤 왼쪽 복귀 중 계단 아래에 갇힌 현상을 고친 것이다. 이동·점프 수치를 바꾸지 않았다. E02 아래 물가에는 해금 상태와 무관한 성소 복귀 출구(7.4,-1.2)를 추가해, 얼음 없이 내려온 경우도 빠져나갈 수 있다.

실험실 05 응용에는 (58,0.85)의 전달 가능한 불씨와 기존 건너편 밧줄을 함께 둔다. (56.7,0)에서 바람 단타로 준비된 불씨를 보내거나, 불 차지→바람으로 검흔 재료를 보내 같은 목표를 태울 수 있다. 준비된 불씨는 위에, 플레이어 검흔 경로는 아래에 두어 전달체가 즉시 재료통에 걸리지 않는다. 환경 재료 전달과 플레이어 검흔 슬롯은 구분한다. 이 비교는 재타격의 재미를 자동 증명하지 않는다.

E06의 선택 발판은 상면2.15/하부1.15로 본선 통행 높이0.88을 확보한다. E02의 위 육로 계단은 하부를 채우지 않아 아래(7.4,-1.2)/(8.8,-1.2)의 복귀 출구를 막지 않는다. 이 두 수정은 전체 재생의 왕복 동선에서 드러난 충돌 문제를 고친 것이다. 실험실 비교 재료 버튼은 준비된 불씨를 제거/복원하며, 없음 상태에서도 불 검흔만으로 같은 밧줄을 열 수 있다.

카메라 하단은 -3.7, 상단9.5로 맞춰 낮은 수면(-1.2)과 S01 바닥이 하단 HUD 위에 남게 했다. 방별 실제 지형/히트박스에는 변경이 없다.
