# 01 · Hwanjo v2 아트 디렉션

작성: 2026-09-24. 대상: `Hwanjo_v2_Test`의 첫 Element Lab 프로토타입.
이 문서는 **첨부 이미지에서 관찰한 내용**과 **현재 게임에 맞추어 제안하는 제작 기준**을 구분한다.
원본 5장은 `references/element-lab-v01/`에 보존한다. 지금 패키지에 새로 만든 게임 스프라이트는 없다.

이미지의 글자와 컷 분할은 시각 자료의 일부다. 그 안에 쓰인 옛 전투 규칙은 현재 구현 지시가 아니다.
PNG 전체를 잘라서 즉시 재생 가능한 sprite sheet라고 가정하지 않는다. 프레임 정렬·해상도·투명도·무기 일관성은 따로 검증한다.

## 2. 현재 게임에 맞춘 방향 — 제작 제안

> 붉은 스카프의 검 여행자 한 명이, 이끼 낀 동양풍 유적에서 네 속성으로 작은 환경 문제를 해결한다.

플레이어는 하나의 외형과 근접 검 하나를 사용한다. 속성 전환은 검·궤적·작은 오라만 바꾸며 머리색·무기·신체 비율을 바꾸지 않는다.
처음에는 REF02와 REF03의 청록 숲/유적을 바탕으로 **실험실 한 테마**를 만든다. 큰 세계 지도나 사방신 네 지역은 만들지 않는다.

앞선 대화에서 이미지 색을 보고 청룡=바람·현무=물 등으로 설명한 부분은 현재 대응 기준이 아니다.
현재 검토 중인 사방신 대응안은 청룡=물 / 주작=불 / 백호=바람 / 현무=얼음이지만 팀 확정은 아니다.
이번 프로토타입 UI와 데이터는 불/물/바람/얼음으로 표시해 그 대응을 미리 확정하지 않는다.

## 3. 주인공 축약 기준

**외형의 우선순위:** 검은 묶음머리 → 붉은 스카프 → 남색/아이보리 의상 구분 → 검 하나 → 소량의 장식.
검집·금색 부적·어깨 보호구는 축약 가능하다. 작은 글자·복잡한 문양보다 실루엣을 우선한다.

다음은 실제 제작용 임시 규격이며, 첨부 그림의 원래 픽셀 격자를 측정한 결과가 아니다.

| 항목 | 시작 규격 |
|---|---|
| 몸체 프레임 | 투명 배경의 48×48 셀. 머리·발·핵심 의상에 여백을 남김 |
| 비율 | 실제 게임에서 읽히는 약 2.5~3등신부터 검토. REF01의 외형과 REF04/05의 작은 캐릭터 동작을 결합 |
| 무기·효과 | 칼·큰 참격은 필요하면 별도 SpriteRenderer/FX 레이어. 몸체를 작게 줄여 효과까지 같은 48×48에 맞추지 않음 |
| 기준점 | 모든 몸체 프레임의 지면·발 중심을 동일하게 맞춤 |
| 크기 | 동일 PPU와 배율을 유지. 뛰거나 공격한다고 머리·몸의 기본 크기가 달라지지 않음 |
| 렌더링 | Sprite import, Point 필터, 불필요한 손실 압축 없이 시작. 흰 배경을 투명이라고 보고하지 않음 |
| 방향 | 오른쪽 원형을 기준으로 좌우 반전 허용. 검·부적의 엄격한 좌우 고증은 이번 실험 범위 밖 |

PPU의 실제 숫자는 새 프로젝트의 카메라/물리 스케일을 확인해서 정한다. 48×48 이미지 크기와 1.75R 게임 사거리는 서로 다른 설계 값이다.

## 4. 필요한 동작 — 네 폼이 아니라 한 캐릭터

| 동작 | 필수로 읽힐 것 | 프레임 수 제안 |
|---|---|---|
| Idle | 호흡·스카프의 작은 움직임 | 4 |
| Run | 다리 교대·몸 중심 이동. 이미지 전체 흔들기만으로 대체하지 않음 | 6 |
| Jump / Fall | 도약과 낙하를 구별 | 각 1~2 |
| Dash | 낮아지는 몸과 전진 자세 | 2~3 |
| 단타 베기 | 준비·접촉·회수의 명확한 포즈 | 5~6 |
| Charge | 검을 모으는 자세 + 준비 완료 신호 | 2~3 |
| Charge Release | 크게 베고 검흔을 남김 | 5~6 |
| Hit / Death | 피격, 쓰러짐을 구별 | 2 / 4~6 |

위 숫자는 이미지 설명을 전사한 확정값이 아니라 제작 시작안이다. **완성 clip 개수보다 실제 동작 품질**을 본다.
모든 속성에서 몸체 단타·차지 동작을 공유한다. 더 큰 VFX를 넣으려고 0.5초 차지·단타 판정·1.75R를 바꾸지 않는다.
애니메이션 타이밍은 게임의 준비/활성/회수 구간에 맞춰 연결하고, VFX가 추가 피해를 독립적으로 발생시키지 않게 한다.

## 5. 네 속성의 시각 언어

이 표는 **신규 제작 제안**이다. 특히 물·바람의 완성 애니메이션 레퍼런스는 이번 다섯 장에 없으므로 ‘원본과 동일’이라고 주장하지 않는다.

| 속성 | 궤적·입자 제안 | 상태 표현 | 조심할 것 |
|---|---|---|---|
| 불 | 밝은 황백색 중심, 주황/붉은 끝, 짧은 불티. REF04 참고 | 표면에 붙은 작은 불꽃·간헐적 DoT 표시 | 사방을 덮는 폭발·세 타짜리 연속 공격으로 바꾸지 않음 |
| 물 | 파란 물결 호, 둥근 방울, 아래로 떨어지는 물방울 | 젖은 표면의 어두운 광택·물방울 | 얼음 결정이나 물 전체의 자유 유체 시뮬레이션과 혼동하지 않음 |
| 바람 | 연한 민트/회백색 가는 호, 방향을 보여주는 공기선 | 물체 이동 방향·검흔 전달을 짧은 선으로 표시 | 스카프색 변경만으로 구분하지 않음. 어디서든 상승기류를 만들지 않음 |
| 얼음 | 희고 차가운 파랑, 짧은 각진 결정. REF05의 대비만 참고 | 명확한 얼음 외피와 상태 종료 균열 | 백호 소환·흰 머리 폼으로 변신시키지 않음 |

## 6. 검기 / 검흔 / 반응을 다르게 보이게 하기

- 검기: 짧게 뻗는 공격 전달. 판정이 지나간 궤적은 빠르게 약해진다.
- 검흔: 차지 뒤 남아 **다시 베어 반응시킬 수 있는 대상**. 생성 위치·현재 속성·남은 시간을 읽을 수 있어야 한다.
- 2차 반응: 기존 검흔이 소비/변환/이동하는 순간만 강조한다. 무엇이 이동했는지 연결을 보여준다.
- 불 검흔→바람: 원래 불 검흔이 사라지며 같은 불이 앞으로 이동한다. 별도 불이 무료로 계속 복제되는 그림 금지.
- 물 검흔→얼음: 물의 움직임이 멈추고 결정으로 변한다. 실제로 발판이면 충돌 가능 면을 뚜렷하게 표시한다.
- 반응 없음: 아주 작은 접촉 신호만. 유효 반응과 같은 크기의 폭발을 내지 않는다.

## 7. 환경·UI·타격감

실험실은 기능적으로 구역을 나누되 같은 숲 유적 미술을 공유한다. 플랫폼 상면·이동 상자·타는 섬유를 장식 배경보다 읽기 쉽게 만든다.
젖음·연소·동결은 색만 바꾸지 말고 물방울/불티/결정 형태를 함께 사용한다.

HUD는 현재 속성·차지 상태·HP·검흔 존재를 우선한다. 최종 게임 HUD 제작이 아니라 실험용 화면이다.
더미 편집기는 드롭다운·토글·Apply/Reset·최근 반응 로그를 읽기 쉽게 구성한다.
UI를 클릭한 행동이 검 공격·속성 변경으로 동시에 전달되지 않게 한다.

Hit Stop·Hit Flash·작은 화면 흔들림은 ON/OFF로 비교한다. DoT 한 틱마다 화면을 멈추지 않는다.
동시에 여러 대상을 때려도 Hit Stop을 대상 수만큼 합산하지 않는다.
피드백은 즉각적으로 보여주되, 연기나 궤적으로 대상 상태와 다음 입력을 가리지 않는다.

## 8. 이미지 생성과 채택 기준

가능하면 제공 이미지를 실제로 열어 본 뒤 **새 게임용 투명 리소스**를 만든다. 이미지 생성 도구의 설치 이름이나 이전 PC의 성공을 현재 사용 가능성으로 단정하지 않는다.
내장 도구를 사용한다. 유료 API 키·추가 과금 서비스·프로그램 설치로 몰래 전환하지 않는다.
이번 작업의 생성/편집 호출은 **총 8회 이내, 동일 산출물 최대 2회**를 제안 한도로 둔다. 소모 예상이 불명확하면 먼저 보고한다.
원본 5장은 덮어쓰지 않는다. 생성 원본·처리 방법·채택 파일을 manifest에 남긴다.

컨셉 시트 전체 축소, 빈 배경 포함 도표 자르기, 같은 포즈를 복사해 이름만 바꾸기, 좌표 이동만으로 모든 애니메이션 처리하기를 완료로 인정하지 않는다.
첫 단타·Run부터 일반 크기와 정수 배율 확대에서 확인한다. 기준을 못 맞추면 사용 가능한 대체 표현으로 게임은 유지하되 **아트 부분 완료**로 보고한다.
이미지 도구가 실제로 작업했어도 외형 일관성과 손맛은 별도 검수 대상이다.
