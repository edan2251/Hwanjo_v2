# v0.3 · 연속 월드 레벨과 최소 벽 행동

## 1. 설계 목표와 지위

**목표: 같은 공간의 위·아래·옆을 기억하고, 새 속성으로 돌아와 지름길을 여는 탐험.**
사용자가 요청한 것은 방 전환 없는 통짜 맵과 자연형 지형, 상하 이동, 벽 이동 보조다.
아래 구역명·좌표 관계·벽 행동 세부값은 제작을 진행하기 위한 **프로토타입용 설계안**이다. 최종 세계 지도·스토리·능력 해금 계획이 아니다.
기존 불→물→얼음→물길 재방문→바람→성소 지름길 순서는 되도록 유지하여 이번 실험에서 바뀌는 변수를 레벨에 집중한다.

## 2. 구조 — 한 지역, 세 높이 층, 두 순환

상층은 수관·뿌리·샘터, 중층은 성소·숲길·갱도 입구, 하층은 물길·오래된 수로다.
주요 랜드마크 6개와 비밀 공간 2개를 실제 지형의 일부로 만든다. 방 개수나 문 통과 수를 채우는 목표가 아니다.
너무 큰 월드보다 10~15분 안팎의 첫 탐험을 목표로 한 소형 루프로 계획하되, 사람이 플레이한 시간을 측정하지 않고 달성했다고 보고하지 않는다.

| ID | 구역 | 역할·시각 단서 | 주요 연결 |
|---|---|---|---|
| Z01 | 입구 성소 | 시작·체크포인트 A. 멀리 중앙 뿌리 구조와 닫힌 귀환길이 보임 | Z02로 출발, Z06에서 귀환 지름길 |
| Z02 | 낮은 숲과 물가 갈림길 | 불로 가연성 장애물 처리. 건너기 어려운 수면과 반대편 수로를 먼저 봄 | Z01·Z03, 얼음 획득 뒤 Z05 |
| Z03 | 중앙 뿌리갱도 | 낮은 안전 발판에서 물 획득. 작은 소화 응용 후 벽 점프로 상층 이동 | Z02↔Z04. 다른 높이에서 다시 알아볼 중심 랜드마크 |
| Z04 | 상층 샘터 | 얼음 획득·체크포인트 B. 발밑 수면 동결을 즉시 연습, 아래 물가를 연상시키는 경관 | Z03로 내려와 Z02에 재방문, S02 선택 공간 |
| Z05 | 하층 수로 | Z02 수면을 얼려 들어오는 구간. 바람 획득, 새 힘을 가까운 기존 반응 장치에 적용 | Z02↔Z06 |
| Z06 | 동쪽 수관과 귀환길 | 두 번째 수직 구간·수관 발판. 바람으로 기존 장치를 움직여 연결하고 뒤쪽에서 성소 지름길 개방 | Z05↔Z01, 이후 자유 순환 |
| S01 | 숲 틈의 작은 기록 공간 | Z02/Z03 근처에서 먼 가연성 연결부·빛 틈을 먼저 봄. 바람 획득 뒤 선택 재방문 | 기존 불 검흔→바람 전달 범위로 해결, 본선 권능 없음 |
| S02 | 샘터 뒤 숨은 전망 공간 | 뿌리 틈·바람에 움직이는 잎·바닥 형태로 관찰 단서. 기본 이동·벽 점프로 선택 진입 | Z04에서 들어가 다시 나올 수 있음, 본선 권능 없음 |

실제 연결 그래프:

```text
Z01 ↔ Z02 ↔ Z03 ↔ Z04
 ↑      │      │      └─ S02
 │      │      └─ S01 (위치는 Z02~Z03 사이에서 조정)
 │      └─ [동결 수면 통로] ↔ Z05 ↔ Z06
 └──────────── [안쪽에서 여는 지름길] ──┘
```

첫 진행:
**Z01 → Z02 → Z03(물) → Z04(얼음) → Z03 하강 → Z02 재방문 → Z05(바람) → Z06 → Z01 지름길.**
그 뒤 이미 본 S01에 돌아가거나 S02를 찾는다. 그림의 선은 실제 이동 통로이며 텔레포트 선이 아니다.
각 구역의 실제 좌표·높이·입구/출구·조건·관찰 단서를 `docs/V03_LEVEL_DESIGN.md`에 기록한다. 게임 월드에서 읽히는 연결이 그래프보다 우선이다.

## 3. 공간의 질

- 최소 두 곳에서 한 번의 점프 높이를 넘는 의미 있는 수직 이동을 만든다. 하나는 상승 중심, 하나는 상승·하강과 갈림길을 섞는다.
- 수직갱도는 동일 높이 발판을 끝없이 반복하는 계단이 아니다. 벽 점프 2~4번 정도의 짧은 묶음, 안전 발판, 주변을 보는 공간을 번갈아 배치하는 것을 시작안으로 삼는다.
- 상층에서 중·하층의 지나온 랜드마크를 알아볼 수 있는 시야를 최소 한 곳 둔다. 비밀 공간의 정답까지 미리 노출하지 않는다.
- 위험 구간 전에는 착지면을 볼 수 있게 한다. 카메라 밖의 바닥으로 무작정 떨어져야 본선이 이어지게 만들지 않는다.
- 화면 외곽을 따라 일렬로 방을 늘어놓지 않는다. 실제 위아래 중첩과 우회 연결을 이용한다.
- 속성·전투·벽 점프를 한 지점에서 동시에 강제하지 않는다. 처음 벽 동작을 배우는 곳에는 기존 적을 붙이지 않는다.
- 숨은 공간에 필수 권능을 넣지 않는다. 작은 기존 발견 표식/보상 2개로 충분하고 새 경제·장비 시스템은 만들지 않는다.
- 같은 직사각 구역에 배경만 바꾼 배치가 아니라 수면·뿌리·절벽·유적의 외곽 형태와 높이 차이로 장소를 구분한다.

## 4. 측정 후 지형 확정

먼저 현재 플레이어의 몸 크기, 최대 일반 점프 높이·수평 이동, 대시 거리·공중 정책, 벽 점프 도달 범위, 기본/차지 R, 바람 전달 실제 거리를 측정한다.
기존 값을 추측해 절대 Unity unit 수치로 맵을 먼저 고정하지 않는다.
필수 점프·1R 상호작용에는 여유를 두고 극한 프레임 타이밍을 요구하지 않는다. 속성 장치의 접촉 면은 해당 방향의 실제 베기 범위 안에 둔다.

| 상황 | 확인 조건 |
|---|---|
| 가연성 줄·덩굴 | 안전하게 설 위치가 있고 수평/위 베기로 닿는다 |
| 물가 | 지상 아래 베기가 실제 노출된 수면을 맞힌다. 물속으로 뛰어들어야만 동결되지 않는다 |
| 수면을 건넌 뒤 | 반대편에서도 안전하게 돌아오거나 리셋할 수 있다 |
| 벽 점프 | 양쪽 벽과 발판에서 머리 끼임·모서리 미끄러짐이 없다 |
| 불→바람 비밀 통로 | 두 번 조작할 공간과 전달선이 있고 기존 실제 전달 거리로 닿는다 |
| 지름길 | 뒤쪽에서 연 후 실제 물리 통로가 열린다. 화면만 바뀌지 않는다 |

벽 이동을 시작부터 쓸 수 있으므로 얼음 해금 전 Z02→Z05를 벽 점프/대시로 우회할 수 있는지 별도 검사한다.
물 폭만 넓히는 대신 천장·돌출 지형·연결되는 벽의 위치를 함께 설계한다. 보이지 않는 금지벽이나 구역별 이동력 변경으로 막지 않는다.
등반 가능 여부를 달리해야 한다면 표면의 생김새·설명과 맞춰야 하며, 관문 전체를 임의 NonClimbable 플래그로 가리는 방법은 마지막 수단도 아닌 재설계 대상으로 본다.
새 이동 때문에 실제 주요 게이트가 불가능하거나 무의미해지면 먼저 지형을 고치고 재검증한다. 단순한 게이트 상태 그래프 검사만으로 실제 점프 우회까지 막혔다고 하지 않는다.

## 5. 벽 행동 — 추가 기능은 이 범위까지만

### 사용 방식

이번 시험에서는 탐험 시작부터 사용하고, 실험실에는 작은 비간섭 시험 벽/발판만 추가할 수 있다. 별도 해금 퀘스트는 만들지 않는다.
기존 점프 입력을 재사용한다. 키를 새로 정하거나 스태미나 HUD를 추가하지 않는다.

| 상황 | 동작 |
|---|---|
| 공중에서 유효 벽을 향해 입력하고 하강 | 벽 슬라이드: 낙하 속도 제한 |
| 벽 슬라이드 중 점프 버튼을 새로 누름 | 벽 반대편·위쪽으로 벽 점프 |
| 벽 접촉이 끊기거나 반대 방향/중립 입력 | 붙잡힘을 해제하고 일반 공중 이동으로 복귀 |
| 착지·피격·사망·리스폰·리셋 | 벽 상태와 입력 버퍼를 정리 |

**벽 슬라이드는 무한 정지형 붙잡기가 아니다.** 천천히 미끄러지되 별도의 짧은 클링·W를 눌러 기어오르기·천장 등반·사다리 시스템은 이번에 추가하지 않는다.
플레이어의 좌우 접촉과 표면 법선으로 벽을 판정한다. 바닥·천장·수면·적·자기 검흔을 벽으로 잘못 인식하지 않는다.
벽의 윗단과 돌출 뿌리를 넘어갈 때 머리와 몸이 박히지 않게 한다. 아트 잔가지까지 촘촘한 충돌로 쓰지 않는다.

### 첫 튜닝안 — 실제 측정 뒤 기록

- 벽 슬라이드 속도는 기존 자연 낙하 최대속도보다 충분히 느리게. 시작 후보는 자연 최대 낙하의 약 25~35%이며 확정값이 아니다.
- 벽 점프 세로 초기속도는 기존 지상 점프 초기속도와 같은 값부터 비교한다. 지상 점프 자체는 바꾸지 않는다.
- 벽 점프 가로 이탈력은 몸 폭과 갱도 간격을 기준으로 좁게 선택한다. 대시처럼 멀리 날리지 않는다.
- 방금 뜬 같은 벽에 즉시 붙는 현상을 막는 짧은 재접촉 제한은 약 0.12초를 시작안으로 시험한다. 이후에는 공중 방향 제어로 돌아갈 수 있다.
- 같은 벽 재점프는 실제로 벽에서 떨어졌다가 다시 접촉하고 새 점프 입력을 했을 때 허용한다. 버튼 유지로 자동 연속 상승하지 않는다. 이 능력으로 올라갈 수 있는 높이를 관문 검사에 반영한다.
- 기존 점프 버퍼·코요테 처리와 합쳐 한 입력으로 지상 점프와 벽 점프가 동시에 나가지 않게 한다. 대시 리셋·추가 점프 자원을 새로 지급하지 않는다.

### 공격·대시와의 최소 연결

기존 공중 단타·지상 차지 정책을 유지한다. 새 공중 차지나 벽 전용 공격을 만들지 않는다.
벽에서 공격·대시를 누르면 벽 상태를 해제하고 기존 해당 행동으로 연결하는 것을 시험안으로 삼는다. 일반 공중 단타가 가능한 조건에서만 실행한다.
기존 차지는 지상을 벗어날 때 취소되는 정책을 유지한다. 착지·지도 닫기·리셋 뒤 오래된 J 해제로 공격이 새로 나가지 않는다.
벽에 매달린다는 이유로 공격 방향이 자동 뒤집히지 않는다. 실제 공격 시점의 방향과 캐릭터/검 표현이 일치해야 한다.
벽 슬라이드 재접촉/낙하 제한은 피격·대시·공격의 유효 상태보다 낮은 우선순위다. 그 행동 도중 매 프레임 벽에 다시 붙어 속도를 덮어쓰지 않는다.
지상 움직임과 단타·차지·원소 반응 수치는 바꾸지 않고, 벽 상태 관련 최소 연결만 수정한다.

## 6. 연속 맵의 상태·지도·리셋

### 구역 경계는 초기화 지점이 아님

- 경계를 넘어도 동일 플레이어, 획득 속성, 열린 길, 적·장치의 논리 상태가 유지된다.
- 검흔/전달체가 영역선을 지나도 타이머가 리셋되거나 소멸하지 않는다. 만료는 기존 수명 정책을 따른다.
- 탐험 수면은 기존 ‘방 리셋 전 유지’ 시험값을 **연속 맵에서 명시적 해당 구역 리셋 또는 전체 재시작 전 유지**로 옮긴다. 이 변경만 기록하고 공통 동결 엔진 수치를 바꾸지 않는다.
- 실험실의 자동 해동·리셋 정책은 별도로 보존한다. 검흔에서 만든 2초 구조와 환경 수면의 유지시간을 합치지 않는다.
- 멀리 간 적이 플레이어를 전 맵 끝까지 쫓도록 AI를 확장하지 않는다. 기존 범위·지역 배치로 동작한다.

### 지도

기존 방문 지도를 월드 배치와 맞게 수정한다. 각 구역의 상대 위치·높이·확인한 연결과 플레이어 현재 위치를 보여준다.
이름만 바꾼 6개 상자를 일렬로 놓지 않는다. 거대한 자동 지도 에디터는 만들지 않고 구역별 발견 영역을 손으로 지정해도 된다.
숨겨진 두 공간은 발견 전 지도 실루엣·아이콘으로 정답을 누설하지 않는다. 이미 본 미해결 통로는 기억할 수 있는 표현을 둔다.

### 체크포인트·초기화

Z01·Z04에 기존 체크포인트 방식 사용. 사망 시 마지막 안전 지점에 복귀하며 권능·지름길·발견은 유지한다.
실행 중 세션 유지까지만 제공한다. 디스크 저장·세이브 슬롯·자동 저장을 추가하지 않는다.
기존 ‘현재 방 다시 시작’ UI는 ‘현재 구역 초기화’ 등 실제 범위가 드러나는 한국어로 수정한다. 확인 후 해당 구역의 재설정 가능한 대상만 초기화한다.
플레이어를 녹는 얼음 위·상자 내부에 남겨두고 지형만 초기화하지 않는다. 해당 구역 안전 지점 또는 체크포인트로 이동시키고 카메라·벽 상태·대기 입력을 정리한다.
획득한 권능과 열린 지름길은 구역 초기화로 되돌리지 않는다. 경계에 걸쳐 있는 대상의 소유 구역을 안정적인 ID로 한 번 정하고 중복 복제하지 않는다.
‘탐험 처음부터’만 명시 확인 후 전체 진행을 초기화한다. 실험실 R·더미 개별 Reset과 섞지 않는다.
