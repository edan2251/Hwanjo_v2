# v0.3 · 자연형 지형, 추가 환경 아트와 연속 카메라

## 1. 방향

**현재 배경과 주인공의 좋은 부분은 보존하고, 새 레벨에 필요한 형태·연결부·수직 공간을 채운다.**
사용자가 원하는 것은 플랫폼이 반복 정사각 타일처럼 보이지 않는 것이다. Tilemap을 기술적으로 전면 금지하거나 엔진을 갈아엎는 요청은 아니다.
충돌/배치는 기존 Tilemap·콜라이더·프리팹 방식을 활용해도 되며, 보이는 외곽을 큰 자연형 스프라이트와 연결 장식으로 정리한다.

원본 5장과 v02 아트의 소스는 보존한다. 새 리소스는 `Assets/ElementLab/Art/V03/`, `VFX/V03/` 등 실제 구조에 맞는 별도 경로를 우선한다.
현재 약 48×48 캐릭터 기준과 기존 PPU·픽셀 밀도를 유지한다. 환경 그림은 더 큰 조각이어도 되지만 인게임 픽셀 크기가 따로 노는 고해상도 사진처럼 만들지 않는다.
참고 이미지를 못 열었다면 추측으로 봤다고 하지 않는다. 기존 게임 화면과 원본을 모두 확인해 스타일을 맞춘다.

## 3. 필요한 환경 리소스 — 파일 수보다 실사용 기준

| 묶음 | 최소 역할 | 실제 적용 기준 |
|---|---|---|
| 자연형 플랫폼 | 긴 지지면·짧은 돌출턱·좌우 끝·이어지는 단차 | 윗면은 읽히고 옆/아래는 흙·바위·뿌리의 비정형 외곽 |
| 벽·절벽 | 긴 수직 면·기둥·돌출부·천장 연결 | 벽 점프 가능한 면이 읽히고 반복 줄무늬·격자 이음새가 덜 보임 |
| 연결 조각 | 뿌리 다리·나무 보·낡은 석조 통로 | 서로 다른 높이 구역이 장면상 자연스럽게 이어짐 |
| 물가·수로 | 둑·젖은 돌·노출 수면·빙결 윗면 | 실제 아래 베기/보행/해동 판정과 시각 면 일치 |
| 랜드마크 | 작은 성소·샘터 제단·중앙 큰 뿌리·바람 반응 장치 | Z01/Z03/Z04/Z05/Z06의 구분과 목적이 색/형태로 읽힘 |
| 지름길·비밀 입구 | 실제 문/뿌리 차단부, 열린 연결부, 빛 틈·파손 흔적 | 단순 문자 표식이 아니라 닫힘/열림 상태가 보임 |
| 배경 보완 | 기존 원경·중경·근경의 상하 확장과 가려졌던 부분 | 수직 이동에서도 투명한 끝·이음새·카메라 밖 빈 공간이 없음 |

같은 사각 발판을 크기만 바꿔 반복하고 잎 장식 몇 개만 붙인 결과로 마무리하지 않는다.
그렇다고 매 지형을 완전히 다른 일회성 원화로 만들어 범위를 폭발시키지 않는다. 소수의 큰 실루엣 조각·전환부·랜드마크를 조합한다.
장식의 복잡함보다 비대칭 외곽·재질 덩어리·장소별 음영과 높이 관계를 먼저 잡는다.

## 4. 충돌과 읽기 쉬운 형태

- 밟는 면과 벽 슬라이드 면은 명확하고 매끄러운 충돌을 유지한다. 그림의 작은 이끼/가시는 비주얼용으로 둔다.
- 외곽은 유기적으로 보여도 필수 지형을 미끄러운 급경사·계단 턱으로 바꾸지 않는다. 기존 이동기가 지원하는 경사 범위 안에서 설계한다.
- Collider를 모든 픽셀 윤곽에 맞추지 않는다. 실제 몸체가 서거나 벽을 탈 주요 면 위주로 단순화한다.
- 보이는 바위 끝보다 Collider가 멀리 돌출하거나, 밟을 것처럼 보이는 뿌리에 판정이 없는 상태를 피한다.
- 가연성 덩굴/밧줄과 장식용 뿌리는 형태·깊이·명암으로 구분한다. 같은 모습인데 어떤 것만 반응하는 혼란을 줄인다.
- 비밀 입구를 완전히 불투명한 장식으로 덮지 않는다. 작지만 발견 가능한 시각 단서를 남긴다.
- 기존 4방향 베기의 유효 범위나 전달선을 환경 아트가 오해시키지 않게 한다. 색만으로 물/얼음/냉기 흔적을 구분하지 않는다.

## 5. 최소 벽 행동 아트

플레이어 전체 동작 10종과 방향별 공격을 다시 만들지 않는다. 새 이동에 필요한 연결만 추가한다.

| 동작 | 기준 |
|---|---|
| 벽 슬라이드 | 손/발이 실제 벽을 향하고 몸·스카프가 하강을 표현. 공중 Idle을 고정한 것과 구분 |
| 벽 점프 | 벽을 밀어내는 접촉 자세 → 이탈 자세 → 기존 Jump/Fall로 연결 |
| 좌우 연결 | 반전 시 벽 접촉면·검·스카프·손 위치가 일치 |
| 작은 효과 | 짧은 마찰 먼지/잎과 점프 시 작은 분출. 긴 대시 잔상이나 속성 폭발로 덮지 않음 |

벽에서 검을 수납하는지 기존 손 위치에 유지하는지 한 방식을 정하고 공격·이탈 때 중복 검이 남지 않게 한다.
새 sprite는 발 피벗·몸 높이·PPU를 기존과 맞추고 몸 collider를 그림에 따라 프레임마다 변경하지 않는다.
몇 개 clip을 만들었는지가 아니라 벽 접촉→이탈→착지의 연속 화면에서 실제로 읽히는지가 완료 기준이다.

## 6. 연속 월드 카메라·패럴랙스

기존 댐핑·3층 레이어를 버리고 새 카메라 패키지를 설치하지 않는다. 실제 구조를 확인해 연속 월드에 필요한 부분만 수정한다.

### 카메라

- 방 출구에서 다음 방 중심으로 카메라가 스냅·고정되는 코드를 v03 일반 이동에서 사용하지 않는다.
- 동일 월드 좌표에서 플레이어를 부드럽게 따라간다. 수직 갱도에서는 위쪽 진행과 안전 착지면을 볼 수 있어야 한다.
- 구역별 프레이밍을 쓰더라도 목표값을 연속적으로 보간하고 경계 진동을 막는다. 조작을 잠그거나 플레이어를 위치 보정해 카메라를 맞추지 않는다.
- 카메라 경계는 화면 반폭·반높이를 고려한다. concave 공간에서는 필요한 배경/가림 지형을 채우고 빈 사각 영역이 보이지 않게 한다.
- 사망·명시적 리셋·메뉴 진입은 예외적으로 카메라 위치/추적 velocity를 초기화하여 긴 화면 비행을 막는다.
- 줌을 계속 바꾸거나 과한 시야 선행·흔들림을 새로 넣지 않는다. 기존 댐핑값에서 시작하고 실제 상하 탐험의 필요에 맞춰 최소 조정·기록한다.

### 패럴랙스

- 기존 3층 색감과 계수 의미를 확인한 뒤 수평뿐 아니라 수직 범위도 커버한다.
- 현재 카메라와 고정된 월드/레이어 기준점으로 위치를 계산한다. 구역 진입 때 원점을 재설정하거나 프레임별 누적으로 드리프트시키지 않는다.
- 지면/물/상호작용 대상은 1:1 월드에 남는다. 배경 스크롤로 실제 판정 대상이 미끄러져 보이지 않게 한다.
- 각 층의 뒤쪽이 움직이며 드러나는 부분을 보완한다. 같은 평면 배경을 투명하게 세 장 중첩하는 것으로 깊이를 대신하지 않는다.
- 근경은 소량 사용해 수면·착지면·벽 접촉·비밀 단서를 가리지 않는다.
- 1366×768와 1920×1080에서 상하좌우 극단을 실제로 확인한다. 물리 좌표나 공격 R를 픽셀 스냅으로 변조해 도트 떨림을 해결하지 않는다.

## 7. 제작 방법·예산

내장 이미지 생성/편집 도구가 실제 사용 가능하면 부족한 환경 조각·랜드마크·벽 자세 제작에 사용한다. 원본/기존 아트 재사용과 코드·텍스처·스프라이트 조합 제작도 허용한다.
별도 유료 API·새 프로그램·계정 생성·웹에서 내려받은 무단 게임 에셋은 사용하지 않는다.
이번 아트 생성·편집 호출 제안 상한은 **10회, 같은 산출물 2회 이내**다. 이 숫자는 품질을 보증하는 값이 아니라 불필요한 반복을 줄이는 작업 한도다. 부족하면 초과를 숨기지 않고 미달·대안·재개 필요를 기록한다.
큰 레벨 전체를 이미지 한 장으로 생성해 Collider만 얹거나, 레퍼런스 설명판을 잘라 게임 sprite처럼 쓰지 않는다.
수정·생성 이미지의 alpha·잘림·픽셀 밀도·pivot·PPU·배치·성능을 확인한 뒤 통합한다. 새 폰트가 필요하면 기존 한글 자산과 라이선스를 확인하고 OS 폰트를 임의 복사하지 않는다.

## 8. C단계 완료 근거

- 주요 6개 랜드마크와 숨은 공간 2곳의 실제 게임 화면. 구조가 바뀐 v02와 비교할 대표 전후 화면.
- 상하·좌우로 경계를 여러 번 오가는 연속 장면. 한 장의 멋진 정지 그림은 스크롤 검증으로 세지 않는다.
- 양쪽 벽 슬라이드→벽 점프→착지의 연속 프레임/영상.
- 지상 수면 동결→실제 보행→해동, 지름길 개방 전후의 그림과 판정.
- F1 OFF에서 임시 네모·숫자/문자 표식·디버그 선이 일반 월드 아트를 대신하지 않는지 확인.
- 새 아트의 파일/소스/사용처/실제 검사/미달 여부를 ART_ASSET_MANIFEST에 기록.

디버그 더미와 테스트 표시는 실험실에 남겨도 된다. 탐험의 제단·문·비석을 단순 글자 표식으로 남기고 필수 아트 완료로 보고하지 않는다.

## 참고 근거와 적용 한계

아래는 방향을 확인할 공식 참고다. 환조의 요구는 플레이어가 말한 연속 맵·동양풍 도트이며, 두 게임의 엔진/씬 구조를 그대로 구현하라는 뜻이 아니다.
- [Ori 공식 사이트](https://www.orithegame.com/): 세계와 미술 소개. 자연형 지형과 레이어 깊이는 이번 환조에 적용할 디자인 해석이다.
- [Team Cherry — The Forgotten Crossroads](https://www.teamcherry.com.au/blog/the-forgotten-crossroads-a-hollow-knight-tour): 연결된 통로·탐험·숨은 지름길의 소개를 참고한다.
