## 4. 더미 편집과 리셋

Q25: Windows 빌드에서 F2로 프리셋·특성 다중 선택·상태·동결 조건 변경 가능.
Q26: Dry+Wet / Burning+Frozen 등 모순 조합 Apply 거부와 설명.
Q27: Apply 뒤 새 특성/상태가 판정에 사용되고 예전 DoT·속도·VFX가 남지 않음.
Q28: 마우스 클릭·숫자 입력창·드롭다운 조작가 플레이어의 공격/속성/리셋을 발동하지 않음.
Q29: Reset Target은 마지막 Apply 복원, Default Preset은 최초 값 복원으로 구분.
Q30: R은 소실된 밧줄/덩굴, 움직인 상자, 물/얼음, 적 HP/상태, 검흔/전달체, 타이머를 복원.

## 5. 적·피격

Q31: 불 3초·0.5초 간격 DoT, 중복 물리 피해 없음. 물로 소화 시 이후 DoT 없음.
Q32: 물의 이동/공격 둔화는 적에게만 적용. animation과 실제 공격 판정 시간 일치.
Q33: 물 둔화가 바람 넉백·중력을 감속시키지 않음.
Q34: 기본 적은 설정된 IntrinsicMoisture로 직접 짧게 동결. 마른 환경도 같이 얼리는 전역 예외는 없음.
Q35: 동결 중 숨은 공격 판정 없음. 해제 후 공격 예고를 거침. 재동결 제한 표시.
Q36: 바람의 수평 밀림+작은 상승, 지형 충돌, 반복 입력으로 무한 재부양 없음.
Q37: 사망·재시작 후 상태 modifier나 AI 타이머가 남지 않음.

## 7. 증거 파일과 PASS 기준

compile 로그/종료 코드, EditMode·PlayMode XML의 총 실행/성공/실패/skip, Windows 빌드 경로,
실제 실행 로그/정상 종료, 더미 UI 실제 입력 결과, 실제 게임 PNG, 필요 동작 연속 프레임,
원본 SHA 비교, git diff 범위, 실제 tuning 값이 있어야 한다.

필수 기능이나 아트가 빠지면 PARTIAL, 유효 빌드가 없으면 BLOCKED. 경고의 영향이 미확정이면 그대로 남긴다.
실측 없이 FPS 목표를 달성했다고 보고하지 않는다. 스크린샷을 찍었다는 사실과 그 내용을 눈으로 검수한 사실을 구분한다.
